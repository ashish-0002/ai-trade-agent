# ARCHX Global - AI Trade & Operations Automation

## Project Overview
An internal automated system designed for international trade operations at ARCHX Global. 

## Key Modules
- **Lead Handler:** Parses international buyer inquiries and drafts responses.
- **Quotation Engine:** Automatically fetches live pricing data to generate export price quotations.
- **Content Automation:** Generates trade-focused digital marketing and social media campaigns.

## Tech Stack
- Python / Flask backend integration with Claude API.
